# Security Policy

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security vulnerability or exploit in the proof-of-compute staking mechanics, quadratic voting weights, or deterministic tribunal slashing routines, please do NOT file a public issue.

Email the maintainer directly at:
**dananjayarox01@gmail.com**

Please include:
1. Proof of concept or reproduction script.
2. Attack vector description (e.g., sybil manipulation, trace spoofing).
3. Proposed remediation or patch if available.
